# 🎂 Cake Bakery Website

## 📌 Project Overview

Cake Bakery is a responsive bakery website designed to showcase different varieties of cakes, desserts, and bakery products. 
The website provides an attractive user interface with product sections, gallery, and contact form to enhance customer interaction and browsing experience.

## ✨ Features

* Responsive navigation bar with dropdown category menu
* Attractive home banner with call-to-action button
* Cake product cards with ratings and pricing
* Gallery section to display bakery items
* About section describing bakery services
* Contact form for user inquiries
* Footer with social media links

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 4
* JavaScript
* AOS Animation Library
* Boxicons

## 📂 Project Structure

```
Cake-Bakery/

```

## 🚀 How to Run

1. Download or clone this repository
2. Open the project folder
3. Run **index.html** in any web browser
